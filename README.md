## 01. Overview

- 에너지 분야(전력 시장, 재생에너지, 계통 운영 등) 관련 논문을 읽고 정리하여 공유하는 저장소입니다.
- 논문은 **발전량 예측 / 수요량 예측 / 전력 가격 예측 / 입찰 전략** 네 가지 주제로 분류합니다.
- 각 논문은 한 줄 요약(핵심 방법론, 데이터, 기여점) 위주로 정리하며, 상세 리뷰가 필요한 경우 별도 문서로 링크합니다.
- 에너지 분야 대표 저널 목록은 [03. Journal Reference](#03-journal-reference)에서 확인할 수 있습니다.

### Convention

- **Reference**: `저자 (연도). 논문 제목` 형식으로 작성하고, 가능하면 DOI/링크를 겁니다.
- **Journal**: 저널 약어를 사용합니다. (약어 ↔ 정식 명칭은 [03. Journal Reference](#03-journal-reference) 참고)
- **Review**: 핵심 내용을 1~2문장으로 요약합니다. 상세 리뷰는 `reviews/` 하위 문서로 링크합니다.
